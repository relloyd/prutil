## Verification status

branch, not by reading alone. The probe tests are reproduced here so they can be

The PR's own claims check out: `go test -count=1 -race ./...` passes on the

## What the PR gets right

`applySave` in `internal/home/settings_store.go` is the correct shape: read the
file, mutate the text, re-parse, compare the result against the `Config` the
mutation was supposed to produce, and only then write.

```go
after, err := ParseConfig(edited)
if err != nil || !reflect.DeepEqual(after, want) {
    return fmt.Errorf("could not change %s without disturbing the rest of it; %w", target, manual)
}
```

**That net holds for every bug below: none of them corrupts `config.yaml`.**
They surface as a refusal to save. Generalising the existing `setBoolSetting`
into this helper was the right move, and the comment-preserving text editing is
worth keeping.

## Blocking

### 1. "Reset to default" can never work on either template setting

`lastLine` (`internal/home/yamledit.go`) deliberately refuses literal and folded
style — `token` returns "is written in a style prutil does not edit" — so
`deleteKey` falls back to `endLine = key.Line` and removes only the
`prompt: |-` line, orphaning the body:

```yaml
herdr:
    Review this pull request      # ← body left behind, now invalid
  dry_run: false
```

`applySave` catches the unparseable result, so pressing `d` on `herdr.prompt`
errors every time instead of resetting.

This is not an edge case. The default config template ships `check_prompt` as a
block scalar, so `d` on it fails **on a fresh install, with no prior editing**:

```go
func TestE2EFreshConfigResetCheckPrompt(t *testing.T) {
	s := OpenIn(t.TempDir())
	if _, err := s.LoadOrCreateConfig(); err != nil {
		t.Fatal(err)
	}
	err := s.ResetSetting([]string{"herdr", "check_prompt"}, func(c *Config) {
		c.Herdr.CheckPrompt = ""
	})
	fmt.Printf("reset check_prompt on a FRESH config -> err=%v\n", err)
}
// reset check_prompt on a FRESH config -> err=could not change …/config.yaml
// without disturbing the rest of it; reset herdr.check_prompt in … by hand
```

**Fix:** `deleteKey` needs the `lastBlockScalarLine` path that `replaceBlock`
already has.

### 2. In-memory config is mutated before the save, and never rolled back

The pattern repeats across every descriptor in `internal/ui/settings_registry.go`
(for example the `herdr.prompt` reset, and each duration `step`/`saveInput`):

```go
a.homeCfg.Herdr.Prompt = home.DefaultPrompt   // happens first
return a.store.ResetSetting(...)              // may fail
```

`a.homeCfg` is the live config the running app polls and hands off with, so a
failed save still changes runtime behaviour until restart, while the UI shows a
value that is not on disk.

Combined with finding 1: press `d` on the prompt, get an error toast, and
handoffs immediately start using the default prompt while `config.yaml` still
holds the custom one.

**Fix:** save first, assign on success.

### 3. A template whose first line is indented can never be saved

`renderBlock` emits a bare `|-`, so YAML infers the block's indentation from the
first non-empty content line:

```
prompt: |-
      Please review:     # infers indent 6
    Be brief.            # dedents out of the block → parse error
```

Verified for both a space-indented first line ("did not find expected key") and
a tab-indented one ("found a tab character where an indentation space is
expected"). A plain first line, a blank first line, and trailing spaces all
round-trip correctly.

```go
func TestProbeBlockIndentedFirstLine(t *testing.T) {
	cases := map[string]string{
		"indented first line": "  Please review:\nBe brief.",
		"leading tab":         "\tPlease review.\nBe brief.",
		"trailing spaces":     "Review this.   \nBe brief.",
		"blank first line":    "\nReview this.",
		"plain":               "Review this.\nBe brief.",
	}
	for name, content := range cases {
		out, err := setBlockScalar([]byte("herdr:\n  dry_run: false\n"),
			[]string{"herdr", "prompt"}, content)
		// … ParseConfig(out), then compare cfg.Herdr.Prompt against content
		_ = name
		_ = out
		_ = err
	}
}
```

**Fix:** emit an explicit indentation indicator (`|4-`), or normalise leading
whitespace before writing.

## Worth fixing

### 4. `formatMapVal` quotes by blacklist and misses most YAML metacharacters

`formatMapVal` quotes only when the value contains `" :#{}\n\r\t\"'"` or is
empty. Probed against a sequence write:

| value | result |
| --- | --- |
| `*star` | does not parse — "unknown anchor 'star' referenced" |
| `[bracket` | does not parse — "did not find expected ',' or ']'" |
| `@at` | does not parse — "found character that cannot start any token" |
| `` `tick `` | does not parse |
| `%pct` | does not parse |
| `&amp` | **parses as an anchor** — round-trips to the wrong value |
| `!bang` | **parses as a tag** — round-trips to the wrong value |
| `owner/repo` | fine |

The last two are the worse case: valid YAML that silently means something else.
`applySave`'s `DeepEqual` catches it, so the write is refused rather than wrong,
but the reader gets the generic "edit it by hand" message.

**Fix:** invert to an allowlist — quote unless the value matches a conservative
safe pattern.

### 5. Reset orphans the deleted key's comment

Verified: given

```yaml
watch:
  # How long to wait when nothing is happening.
  idle_interval: 5m
  base_interval: 1m
```

resetting `watch.idle_interval` leaves the comment behind, where it now reads as
documentation for `base_interval`. Directly against the comment-preservation
goal stated in `yamledit.go`'s own doc comment.

### 6. Root validation was dropped in the new entry points

The pre-existing `setScalar` checks that the root is a mapping *and* not flow
style:

```go
if root.Kind != yaml.MappingNode || root.Style&yaml.FlowStyle != 0 {
	return nil, errors.New("the configuration is not a set of keys written one per line")
}
```

`setBlockScalar` checks only `Kind`. `setMapEntry`, `setSequence`, `deleteKey`
and `deleteMapEntry` check neither before calling `indentUnit(root)` and walking
it. Safe today only because `applySave` catches the mess.

`setBlockScalar` also returns the raw `yaml.Unmarshal` error rather than the
wrapped "could not read the configuration" message the others use.

### 7. Test gap

`TestDeleteKeyRemovesKeyFromYAML` covers a single-line scalar only. No test
round-trips write-then-reset — one test doing `SaveBlockScalar` followed by
`ResetSetting` would have caught findings 1 and 3 together.

## Design comment, not a defect

`internal/ui/settings_registry.go` is 1,328 lines for 23 settings. Each duration
descriptor repeats roughly 55 lines of near-identical closures —
`getDisplay`, `getRaw`, `isDefault`, `step`, `saveInput`, `reset` — differing
only in the config field and the label. The PR describes the architecture as
"adding a future setting requires only adding a `settingDescriptor`", which is
true but costs far more per setting than that phrasing suggests.

A helper parameterised on a field accessor plus path would collapse most of the
file. Worth raising before this becomes the pattern every future setting copies.
